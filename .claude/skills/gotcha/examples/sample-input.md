# PRD: Snooze on Notifications

We want users to be able to snooze a notification instead of just dismissing
it. When a user taps "Remind me later" on a notification, it disappears and
comes back in 1 hour.

## Requirements
- Add a "Remind me later" action to all notifications.
- Snoozed notifications reappear after 1 hour.
- Ship in the next release.

## Success metric
Users engage more with notifications after this ships.
